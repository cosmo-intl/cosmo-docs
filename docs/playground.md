# Playground

Try the `@miloun/cosmo` JavaScript port in your browser. Formatting uses your
browser's `Intl` API; values are computed locally.

Choose a locale or enter a BCP-47 tag, then optionally set a time zone and
currency. The table updates as you change the settings. If your browser does not
support a method, its result shows the error.
