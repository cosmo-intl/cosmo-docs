From the everyday — US dollars, the Gregorian calendar, New York time, Latin script — to the long tail: the Persian and Ethiopic calendars, Nepal's UTC+5:45, the Adlam and Tifinagh scripts, and Eastern-Arabic numerals (٢٠٢٠).

⚡

Zero locale data

Language names, calendars, currencies and formatting rules come from ICU. Cosmo does not maintain its own locale tables.

🌍

The same API everywhere

Shared operations across JavaScript, PHP, Python, Java and C#, with naming and parameter types suited to each language. Select a code tab to read examples in your language throughout the site.

💱

Formatting and text tools

Money, dates, numbers, units, percentages, plurals, lists, ranges, collation, transliteration and parsing — all in the locale's conventions.

🧩

Runtime support

Available features depend on each language's ICU APIs. The platform notes explain which methods are supported and where behaviour differs.
